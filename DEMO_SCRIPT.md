# Demo-script – TrueKind

## 1. Börja på startsidan
Visa att TrueKind har en mjukare och mer premium känsla än en vanlig dejtingsapp.

Poänger att nämna:
- mindre brus
- mer närvaro
- mer fokus på personlighet, känsla och röst

## 2. Gå till onboarding
Visa att användaren fyller i mer än bara grunddata.

Poänger att nämna:
- vad man söker
- intressen
- bio
- personlig tanke

## 3. Gå till discover
Visa att profilerna känns rikare och mer mänskliga.

Poänger att nämna:
- tydligare profilkort
- intressen
- personlig tanke
- mjukare matchupplevelse

## 4. Likea en profil
Visa att användaren går vidare till match.

Poänger att nämna:
- tydlig övergång från upptäckt till kontakt
- känslan av ett naturligt nästa steg

## 5. Gå till messages
Visa att chatten känns levande.

Poänger att nämna:
- separata chattar per match
- senaste meddelande i matchlistan
- oläst-känsla
- tidsstämplar

## 6. Visa profilsidan
Visa att profilen går att redigera direkt.

Poänger att nämna:
- användaren kan uppdatera sin identitet löpande
- samma data används i flera vyer

## 7. Visa röstprofil
Visa att TrueKind skiljer sig från enklare appar genom röst.

Poänger att nämna:
- röst skapar mer känsla och närvaro
- kan bli en tydlig differentierande funktion senare

## 8. Avsluta med nästa steg
Förklara att detta är en MVP-demo.

Bra avslut:
- nästa steg kan vara riktig backend
- riktig auth
- riktiga profiler
- bilduppladdning
- riktig rösthantering
