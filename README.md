# TrueKind

TrueKind är en lokal MVP-prototyp för en mjukare och mer mänsklig dejtingsupplevelse.

## Funktioner i demon

- Premium startsida
- Login / register
- Onboarding med rikare profilfält
- Discover med mock-profiler
- Match-sida
- Matchlista
- Separata chattar per match
- Profilsida med redigerering
- Röstprofil
- Lokal lagring via localStorage

## Teknik

- Next.js
- React
- TypeScript
- localStorage för demo-data

## Starta projektet

Öppna terminal i projektmappen och kör:

```bash
npm install
npm run dev
