- [ ] Startsidan visas korrekt

### Onboarding
- [ ] Det går att fylla i namn

### Matchlista
- [ ] Senaste match visas

### Profil
- [ ] Profilinfo visas korrekt

- [ ] Röstprofilstatus visas

### Voice
- [ ] Mikrofontillgång fungerar
